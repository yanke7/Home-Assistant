# Home Assistant

Custom dashboard cards for my Home Assistant setup.

| Folder | What it is |
|--------|------------|
| [Main Dashboard card](Main%20Dashboard%20card) | Yanke Pulse: a living hero card with sky, moon phase, clock and home status |
| [Fable Sun Moon](Fable%20Sun%20Moon) | Almanac: a self-contained sun and moon card with a scrubbable day chart, phase calendar and sky map |
| [Office set up](Office%20set%20up) | Mac workstation, Apple TV remote and apps, office lighting, temperature and Brother toner |
| [Network](Network) | Responsive network console with speed history, device status and printer supplies |
| [Themes](Themes) | Shared appearance settings: ten palettes, five fonts, and global text sizing |
| [Echo Show Remote](Echo%20Show%20Remote) | Alexa skill that puts a touch remote for the Office Apple TV on an Echo Show, opened automatically when the Apple TV turns on |
